Privacy Policy

Last Updated: January 2025 | Version 1.0

Privacy at a Glance

  • No login required
  • No personal data collected
  • Predictions run locally in your browser
  • Data never sold
  • Anonymous analytics only

1. What We Collect

We use PostHog to collect anonymous analytics about how the extension is used:

  • Page URLs where the extension runs
  • Event types (e.g., "prediction completed")
  • Property metadata (bedrooms, postcode district)
  • Extension version

We store one randomly-generated identifier locally to distinguish unique installations. This ID is not linked to your identity.

2. How We Use Data

Analytics data is used to:

  • Improve extension features
  • Fix bugs and errors
  • Understand usage patterns

3. Local Processing

All rent predictions are calculated entirely within your browser using a pre-trained machine learning model. Property data from listings is processed locally and never sent to external servers.

4. Third-Party Services

  • PostHog: Anonymous usage analytics
  • GitHub: Hosts ML model files (no user data sent)

5. Your Rights

  • Delete data: Uninstall the extension to delete all locally stored data
  • Opt out: Block us.i.posthog.com to disable analytics
  • Contact us: Email hello@rentfairvalue.com for data requests

6. Contact

For privacy inquiries: hello@rentfairvalue.com
